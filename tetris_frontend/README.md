# Modern Tetris (Ocean Professional)

A modern, responsive Tetris built with React. Keyboard controls, live stats, next-piece preview, and light/dark theme toggle.

## Run

- `npm start` — Development server at http://localhost:3000
- `npm test` — Run tests
- `npm run build` — Production build

## Play

- Start: Enter
- Move: ← → 
- Soft drop: ↓
- Hard drop: Space
- Rotate: Z (CCW), X or ↑ (CW)
- Pause/Resume: P
- Restart: R

## Notes

- Sidebar shows Score, Level, Lines, Next piece preview, and persists a local High Score.
- The layout is responsive; sidebar stacks below the board on narrow screens.
- Theme toggle in the header switches light/dark using data-theme.
